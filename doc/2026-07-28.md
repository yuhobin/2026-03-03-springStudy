## 1. HTTP 요청 방식과 매핑 어노테이션

Spring에서 HTTP 요청 방식에 따라 다른 매핑 어노테이션을 사용한다.

| 어노테이션 | 요청 발생 상황 |
|-----------|-------------|
| `@GetMapping` | `<a>`, `sendRedirect()`, `location.href`, 브라우저 주소창 직접 입력 |
| `@PostMapping` | `<form method="post">`, `axios.post()`, `$.ajax({ type: 'post' })` |
| `@RequestMapping` | GET / POST 모두 처리 (두 방식을 함께 받아야 할 때) |

**GET / POST 용도 구분**

- GET : 화면 요청, 데이터 조회 (검색 결과 표시)
- POST : 데이터 전송 (검색 조건 전달, 저장, 로그인 등)

## 2. REST API 매핑

다른 프로그램(React, Vue 등 프론트엔드)과 데이터를 주고받을 때 사용하는 방식으로, HTTP 메서드로 CRUD를 표현한다.

| 어노테이션 | CRUD | Axios |
|-----------|------|-------|
| `@GetMapping` | SELECT (조회) | `axios.get()` |
| `@PostMapping` | INSERT (등록) | `axios.post()` |
| `@PutMapping` | UPDATE (수정) | `axios.put()` |
| `@DeleteMapping` | DELETE (삭제) | `axios.delete()` |

- REST API에서는 `HttpServletRequest`를 직접 사용하지 않음
- DispatcherServlet이 요청 파라미터를 매개변수에 자동으로 주입
- 매개변수 순서는 상관없으며, **key명과 동일한 변수명**으로 자동 매핑

## 3. Controller 매개변수 처리

Spring Controller는 다양한 형태로 요청 데이터를 받을 수 있다.

**1) 기본 데이터 수신**
- 파라미터 key명과 동일한 변수명으로 자동 매핑
- null이 올 수 있거나 타입이 애매한 경우 `String`으로 받는 것이 안전

**2) 다양한 매개변수 유형**

| 형태 | 예시 | 용도 |
|------|------|------|
| 내장 객체 | `HttpSession session` | 세션 직접 접근 |
| 배열 | `String[] hobby` | 체크박스 다중 선택 |
| 리스트 | `List<String> list` | 동적 입력 폼 (`name="list[0]"`) |
| 데이터 전송 | `Model model` | View로 데이터 전달 |
| 리다이렉트 | `RedirectAttributes ra` | 리다이렉트 시 데이터 전달 |

**3) 리다이렉트 데이터 전달**
```
RedirectAttributes.addAttribute("no", 1)
return "redirect:../food/detail.do"
```
- `addAttribute` : URL 파라미터로 전달 (주소창에 노출)
- `addFlashAttribute` : 1회성 전달 (주소창에 미노출)

## 4. Controller 구조와 처리 흐름

**@Controller vs @RestController**

| 어노테이션 | return 타입 | 용도 |
|-----------|------------|------|
| `@Controller` | `String` (JSP 경로) | 화면 이동 (Router 역할) |
| `@Controller` | `void` | 파일 다운로드 등 |
| `@RestController` | 객체 / 데이터 | REST API (JSON 응답) |

**전체 처리 흐름**

```
요청 → DispatcherServlet → Controller → Service → Mapper(Repository) → DB
                                                                         ↓
응답 ← JSP(View) ← Controller ← Service ← Mapper(Repository) ←←←←←←←←←
```

- 데이터 전달 객체로 `Model`을 사용해 Controller → View로 데이터를 넘김

| 백엔드 | 프론트엔드 |

| Spring Boot | React |
| FastAPI (Python) | Vue / React |

- REST API에서는 `HttpServletRequest` 없이 매개변수만으로 깔끔하게 데이터를 받을 수 있다는 점이 기존 Servlet 방식과의 큰 차이임을 이해함
- `@Controller`(화면 이동)와 `@RestController`(데이터 응답)의 역할 차이를 명확히 구분하게 됨
