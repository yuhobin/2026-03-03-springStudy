## 1. XML 파싱 개요

XML 문서에서 필요한 데이터를 추출하는 기술로, 크게 두 가지 방식이 있다.

| 방식 | 특징 |
|------|------|
| **DOM** | XML 전체를 메모리에 트리 구조로 로드 후 탐색. 메모리 소비가 크지만 자유롭게 탐색 가능 |
| **SAX** | XML을 한 줄씩 순차적으로 읽으며 이벤트 방식으로 처리. 메모리 효율적 |

> Spring과 MyBatis는 **SAX 방식**을 기반으로 XML 설정 파일을 읽는다.

---

## 2. SAX 파싱 동작 방식

XML을 위에서 아래로 한 줄씩 읽으면서 특정 태그를 만날 때마다 이벤트 메서드가 자동으로 호출된다.

```xml
<?xml version="1.0" encoding="UTF-8"?>   ← startDocument()
<beans>                                   ← startElement()
  <bean id="sa" class="com.sist.main.Sawon"  ← startElement()
    p:sabun="1"
    p:name="홍길동"
    p:dept="개발부"
    p:job="사원"
  />                                      ← endElement()
</beans>                                  ← endDocument()
```

**이벤트 메서드 호출 순서**

| 순서 | 이벤트 메서드 | 호출 시점 |
|------|------------|---------|
| 1 | `startDocument()` | XML 문서 시작 (`<?xml ...?>`) |
| 2 | `startElement()` | 여는 태그 만날 때 (`<beans>`, `<bean ...>`) |
| 3 | `endElement()` | 닫는 태그 만날 때 (`/>`, `</beans>`) |
| 4 | `endDocument()` | XML 문서 끝 |

---

## 3. Spring / MyBatis에서의 활용

Spring과 MyBatis는 SAX 파싱을 내부적으로 활용해 XML 설정 파일을 읽고 처리한다.

**Spring** : `applicationContext.xml`의 `<bean>` 태그를 SAX로 읽어 클래스를 찾고 객체를 생성 → Container에 등록  
**MyBatis** : `Mapper.xml`의 SQL 태그를 SAX로 읽어 쿼리를 추출 → 실행

> 개발자가 직접 파싱 코드를 작성할 일은 없지만, Spring / MyBatis가 XML 설정을 어떻게 읽는지 내부 동작 원리를 이해하는 데 핵심이 되는 개념이다.
